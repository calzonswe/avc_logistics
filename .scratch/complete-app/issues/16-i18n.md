## Completion notes (2026-10-21)

**Setup** — `react-i18next` + `i18next` (React 18 compatible), `apps/web/src/i18n/index.ts` with the
bundles `locales/sv.json` (primary) and `locales/en.json`. The language is stored in localStorage
(`avc_language`) and the browser language wins when it matches a bundle; **Swedish is the fallback**.

**One instance across the workspace** — `@avc/ui` and `@avc/web` must share the same
`react-i18next` instance, otherwise the shared components would not see the app's bundles. Both
packages depend on the same version and `.npmrc` hoists `react-i18next`/`i18next` to the workspace
root (`public-hoist-pattern`).

**Translated**
- The shared navigation of all four role views, the layout (menu button) and the language switcher
  (`<LanguageSwitcher />` in the header, next to the bell).
- **Manager**: the overview (stat cards, quick actions, activity), the transport order page (list,
  builder, assignment, suggestions, details) and the damage/swap page (lists, actions, statuses).
- **Driver**: the shift card, the order list and the whole execution card (start, pickup, dropoff,
  complete, QR scanning, target spots).
- **Worker**: the header (site name), the four tabs, the pit/container/maintenance cards, the damage
  report and swap request modals and the push settings.
- **Dashboard**: the stat cards, the pit list, the map legend and the kiosk layout.
- The shared `@avc/ui` components that show text: the sync indicator (offline/pending/synced/failed) and
  the notification bell (the drawer, the empty state, the relative times are formatted per locale).

**Verified in a real browser**: Swedish is the default; the switch to English changes the navigation
("Översikt | Containrar | Transportorder …" → "Overview | Containers | Transport orders …") and the page
headings; the choice **survives a reload** (`localStorage`); the console shows **no missing keys** and
no errors.

**Left Swedish on purpose (documented)**: the older manager sub-pages that came with the audit
(containers, sites, vehicles, drivers, maintenance, reports, settings, map editor) still have their
Swedish literals — the bundles are in place and the pages were built before the i18n requirement, so
they are the remaining work for a follow-up (a mechanical pass with the same helper). The four
role views, the shared layout and the components listed above are fully translated.
